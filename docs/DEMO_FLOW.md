# Demo Flow

## Setup

```bash
pnpm demo:setup
docker compose up
```

Open `http://localhost:3000`.

## Flow

1. Landing page
   - Say: Universe Studio creates worlds, not clips.
   - Click `Demo Mode`.

2. Universe detail
   - Show `Memory Market 2094`.
   - Explain the premise: memories are bought and sold as currency.

3. Character dossiers
   - Open Maya Orin.
   - Show identity, status, goals, relationships, knowledge, and life events.
   - Open Jax Vey if time allows.

4. Memory Explorer
   - Show graph nodes.
   - Point out characters, events, locations, objects, and edges.
   - Explain that this is the universe memory, not generated text.

5. Episode viewer
   - Open `The Price of Recall`.
   - Show screenplay scenes.
   - Switch to `Agent Trace`.
   - Explain the cooperating agents.

6. Timeline workbench
   - Compare Timeline A and Timeline B.
   - Timeline A: Maya survives.
   - Timeline B: Maya dies.
   - Show changed events, relationship differences, and state differences.

7. Alternate future
   - Open `The City Without Maya`.
   - Show that the episode reflects Timeline B, not Timeline A.

8. Consistency dashboard
   - Show continuity checks.
   - Explain that generated content is validated before persistence.

## Closing Line

Universe Studio is a versioned memory engine for cinematic worlds. The demo shows
that changing history changes the future.
