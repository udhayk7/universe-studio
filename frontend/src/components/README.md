# Components

Component folders are organized by product surface, not by technical type.

- `ui`: ShadCN-generated primitives only.
- `layout`: App shell, navigation, and page framing.
- `studio`: Universe creation and dashboard components.
- `graph`: React Flow graph nodes, edges, and controls.
- `timeline`: Timeline and branch visualization.
- `memory`: Memory inspector and character dossier surfaces.
- `episodes`: Episode generation and display surfaces.
- `common`: Shared presentational components that are not ShadCN primitives.
- `providers`: React providers such as TanStack Query.
